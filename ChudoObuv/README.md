## Ответы на контрольные вопросы

1. **Как объявить переменную? Какие типы данных вы знаете?** Переменная создаётся присваиванием: `price = 8990.0`.
   Основные типы: `int` (5), `float` (8990.0), `str` ('Air Max'), `bool` (True/False); коллекции `list`, `dict`, `tuple`, `set`.
2. **Что делает print? Чем отличается от input?** `print()` выводит значения в консоль; `input()` читает строку,
   введённую пользователем с клавиатуры, и всегда возвращает `str` (для чисел нужен `int()`/`float()`).
3. **Для чего нужен цикл for? Чем он отличается от while?** `for` перебирает элементы коллекции или диапазона —
   число повторений определяется данными; `while` повторяет блок, пока истинно условие, и требует самостоятельно
   менять переменную условия (иначе бесконечный цикл).
4. **Что делает range(5)? А range(1, 6)?** `range(5)` → 0, 1, 2, 3, 4; `range(1, 6)` → 1, 2, 3, 4, 5 (конец не включается).
5. **Чем список отличается от словаря?** Список — упорядоченная последовательность, доступ по индексу `sizes[0]`;
   словарь — пары «ключ — значение», доступ по ключу `product['name']`, ключи уникальны.
6. **Что такое кортеж? Когда он удобен?** Неизменяемая последовательность `(36.0, 5)`; удобен для фиксированных
   данных (пара «размер, количество», координаты), может быть ключом словаря.
7. **Как отсортировать список словарей по ключу?** `sorted(products, key=lambda p: p['price'])` или
   `products.sort(key=lambda p: p['name'], reverse=True)`.
8. **Что такое lambda?** Короткая безымянная функция из одного выражения: `lambda p: p['price']` — «взять `p`, вернуть его цену».
9. **Как отфильтровать список с помощью спискового включения?** `[p for p in products if p['price'] < 6000]`.
10. **Что делает return в функции?** Завершает функцию и возвращает результат вызывающему коду; без `return` функция возвращает `None`.
