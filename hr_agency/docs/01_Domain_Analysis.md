## Введение

Современная деятельность организаций практически невозможна без использования информационных систем. Большой объём информации, который необходимо получать, хранить, обрабатывать и передавать между сотрудниками, требует применения автоматизированных средств. Особенно это актуально для организаций, деятельность которых непосредственно связана с обработкой больших массивов данных.

В рамках данной практической работы рассматривается предметная область кадрового агентства. Основной деятельностью кадрового агентства является содействие трудоустройству граждан, находящихся в поиске работы, а также взаимодействие с предприятиями, располагающими вакантными рабочими местами.

В процессе своей работы кадровое агентство получает и обрабатывает сведения о соискателях, вакансиях, работодателях, результатах собеседований и трудоустройства. При использовании преимущественно ручного способа обработки такой информации возникает большое количество потенциальных проблем: дублирование данных, потеря информации, сложность поиска подходящей вакансии, увеличение времени обработки заявок и вероятность возникновения ошибок.

Для решения перечисленных проблем предлагается разработать информационную систему кадрового агентства, предназначенную для автоматизации основных информационных процессов организации.

Целью практической работы является анализ выбранной предметной области, определение назначения информационной системы, оценка целесообразности её разработки, определение пользователей, места размещения, комплекса технических средств и системного программного обеспечения.

## Выбор предметной области

В качестве предметной области для разработки информационной системы выбрано кадровое агентство.

Кадровое агентство представляет собой организацию, основной зада

чей которой является содействие трудоустройству граждан и подбор сотрудников для предприятий и организаций.

Деятельность кадрового агентства включает следующие основные процессы:

- регистрацию новых соискателей;
- хранение информации о соискателях;
- обработку резюме;
- регистрацию работодателей;
- добавление и редактирование вакансий;
- поиск подходящих вакансий для соискателей;
- подбор кандидатов для работодателей;
- организацию и фиксацию результатов собеседований;
- регистрацию фактов трудоустройства;
- ведение статистики;
- формирование отчётности;
- подготовку информации для налоговых органов и органов государственной статистики.

Таким образом, деятельность кадрового агентства характеризуется большим количеством взаимосвязанных информационных процессов.

Основными объектами предметной области являются:

- соискатель;
- резюме;
- работодатель;
- вакансия;
- сотрудник кадрового агентства;
- собеседование;
- трудоустройство;
- отчёт.

Между перечисленными объектами существуют определённые связи. Например, один соискатель может иметь одно или несколько резюме, работодатель может размещать несколько вакансий, а на одну вакансию может претендовать несколько соискателей.

Информационная система должна учитывать указанные взаимосвязи и обеспечивать возможность получения актуальной информации о состоя

нии предметной области.

Сокращённое обозначение системы — ИС «КадрПро».

## Определение цели информационной системы

Основной целью информационной системы «КадрПро» является автоматизация информационных процессов кадрового агентства для повышения скорости обработки информации, снижения количества ошибок и повышения эффективности взаимодействия между сотрудниками агентства, соискателями и работодателями.

Для достижения основной цели необходимо реализовать следующие задачи:

- создание единой базы данных соискателей;
- создание единой базы данных работодателей;
- ведение базы данных вакансий;
- автоматизация поиска вакансий по заданным параметрам;
- автоматизация подбора кандидатов;
- хранение и обработка резюме;
- регистрация результатов собеседований;
- фиксация информации о трудоустройстве;
- формирование статистической информации;
- формирование отчётов;
- разграничение прав доступа пользователей;
- обеспечение сохранности информации;
- сокращение времени выполнения типовых операций.

Основной результат внедрения системы заключается в переходе от разрозненного хранения данных к централизованному хранению и обработке информации.

## Анализ осуществимости информационной системы

Анализ осуществимости необходим для определения того, насколько целесообразна разработка и внедрение информационной системы в рассматриваемой организации.

При анализе учитываются организационные, технические и экономические факторы.

В данном случае предполагается, что кадровое агентство является организацией среднего размера, в которой работают руководитель, несколько менеджеров по подбору персонала и административные сотрудники.

Разработка информационной системы является технически осуществимой, поскольку необходимые технологии являются распространёнными и не требуют создания принципиально новых аппаратных или программных решений.

Для функционирования системы необходимы:

- персональные компьютеры сотрудников;
- локальная вычислительная сеть;
- подключение к сети Интернет;
- сервер или облачная серверная инфраструктура;
- система управления базами данных;
- серверное и клиентское программное обеспечение;
- средства резервного копирования.

### Что произойдёт с организацией, если система не будет введена в эксплуатацию?

В случае отказа от внедрения информационной системы кадровое агентство сможет продолжить работу, однако значительная часть операций будет выполняться вручную или с использованием разрозненных программных средств.

Это может привести к следующим последствиям:

- Увеличится время обработки заявок соискателей.

Сотруднику агентства потребуется вручную просматривать резюме и сопоставлять их с вакансиями.

- Повысится вероятность ошибок.

При ручном вводе и переносе информации возможно появление опечаток, дублирования записей и потери данных.

- Усложнится поиск информации.

При большом количестве резюме и вакансий поиск необходимых данных вручную станет трудоёмким.

- Возникнут проблемы с актуальностью информации.

Например, вакансия может быть уже закрыта, однако в документах она всё ещё будет числиться активной.

- Увеличится нагрузка на сотрудников.

Большое количество рутинных операций будет выполняться вручную.

- Усложнится подготовка отчётности.

Для формирования статистики сотрудникам потребуется самостоятельно собирать информацию из различных источников.

- Повысится риск потери данных.

При хранении информации только в локальных документах или бумажных носителях возможна потеря данных вследствие технических неисправностей, повреждения документов или человеческого фактора.

Таким образом, отсутствие информационной системы не приведёт к немедленной остановке деятельности кадрового агентства, однако по мере увеличения количества клиентов и вакансий эффективность ручной обработки информации будет снижаться.

## Размещение информационной системы и пользователи

Информационная система «КадрПро» предполагается к размещению в офисе кадрового агентства с использованием серверной инфраструктуры.

Возможна следующая архитектура:

- сервер базы данных;
- сервер приложений;
- рабочие станции сотрудников;
- сетевое оборудование;
- периферийные устройства.

В небольшом кадровом агентстве сервер базы данных и сервер приложений могут быть объединены на одном физическом сервере.

Для обеспечения возможности удалённого доступа система может быть размещена на арендованном облачном сервере. В таком случае пользователи будут подключаться к системе через веббраузер.

Основными пользователями ИС являются:

- руководитель кадрового агентства;
- менеджер по подбору персонала;
- специалист по работе с соискателями;
- специалист по работе с работодателями;
- администратор информационной системы;
- бухгалтер или сотрудник, ответственный за отчётность.

Для различных категорий пользователей необходимо предусмотреть разграничение прав доступа.

Например, администратор должен иметь доступ к настройкам системы и управлению учётными записями, тогда как менеджер по подбору персонала должен работать преимущественно с вакансиями, соискателями и собеседованиями.

## Системное программное обеспечение информационной системы

Системное программное обеспечение предназначено для обеспечения работы аппаратных средств компьютеров, серверов и сетевого оборудова

ния, а также для создания среды выполнения прикладного программного обеспечения.

Для ИС «КадрПро» необходимо следующее системное программное обеспечение.

### Операционная система рабочих станций

На рабочих станциях сотрудников может использоваться современная операционная система, например Microsoft Windows 11.

Операционная система обеспечивает:

- взаимодействие пользователя с компьютером;
- управление файлами;
- управление оперативной памятью;
- управление подключёнными устройствами;
- работу сетевых соединений;
- запуск прикладного программного обеспечения.

В качестве альтернативы может использоваться Linux, если организация предпочитает свободное программное обеспечение.

### Операционная система сервера

Для серверной части системы целесообразно использовать серверную операционную систему Linux, например Ubuntu Server или Debian.

Серверная ОС должна обеспечивать:

- стабильную круглосуточную работу;
- управление пользователями;
- управление сетевыми соединениями;
- запуск серверных приложений;
- работу системы управления базами данных;
- ведение системных журналов;
- настройку резервного копирования;
- обеспечение безопасности сервера.

### Система управления базами данных

Для хранения информации ИС необходима система управления базами данных.

В качестве СУБД может использоваться PostgreSQL.

В базе данных предполагается хранить следующие основные сущно

сти:

- пользователи;
- сотрудники;
- соискатели;
- резюме;
- работодатели;
- вакансии;
- навыки;
- собеседования;
- результаты собеседований;
- факты трудоустройства;
- отчёты;
- журнал действий пользователей.

Использование реляционной СУБД позволит обеспечить целостность

данных и установить связи между объектами предметной области.

### Резервное копирование

Для предотвращения потери информации необходимо организовать регулярное резервное копирование базы данных.

Резервные копии могут создаваться автоматически, например один раз в сутки.

Рекомендуется использовать несколько уровней хранения:

- основная база данных;
- локальная резервная копия;
- отдельная резервная копия на другом носителе или сервере.

При возникновении аппаратного сбоя, повреждении базы данных или другой аварийной ситуации резервная копия позволит восстановить работоспособность системы.

## Основные функции информационной системы

Информационная система «КадрПро» должна обеспечивать выполнение следующих функций.

### Работа с соискателями

Сотрудник кадрового агентства должен иметь возможность:

- зарегистрировать нового соискателя;
- изменить его контактные данные;
- добавить резюме;
- изменить статус соискателя;
- указать профессиональные навыки;
- просмотреть историю взаимодействия;
- найти подходящие вакансии.

### Работа с работодателями

Система должна позволять:

- регистрировать работодателя;
- хранить контактную информацию;
- добавлять вакансии;
- редактировать вакансии;
- закрывать вакансии;
- просматривать историю сотрудничества.

### Работа с вакансиями

Для каждой вакансии должны храниться:

- название должности;
- организация;
- описание обязанностей;
- требования к кандидату;
- уровень заработной платы;
- тип занятости;
- график работы;
- необходимые навыки;
- дата публикации;
- статус вакансии.

### Подбор кандидатов

Система должна обеспечивать автоматизированный поиск кандида

тов.

Поиск может осуществляться по следующим параметрам:

- специальность;
- опыт работы;
- образование;
- навыки;
- ожидаемая заработная плата;
- город;
- тип занятости;
- график работы.

Результатом поиска должен являться список кандидатов, соответствующих заданным параметрам.

### Учёт трудоустройства

После успешного завершения процедуры подбора сотрудник кадрового агентства фиксирует факт трудоустройства.

Для записи трудоустройства необходимо сохранить:

- идентификатор соискателя;
- идентификатор работодателя;
- идентификатор вакансии;
- дату трудоустройства;
- должность;
- статус трудоустройства.

После регистрации трудоустройства соответствующая вакансия может быть переведена в состояние «Закрыта», если дополнительный набор сотрудников больше не требуется.

В рамках работы была определена основная цель системы, заключающаяся в автоматизации сбора, хранения, обработки и предоставления информации о соискателях, работодателях и вакансиях.
