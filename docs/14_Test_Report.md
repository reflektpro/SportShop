## Найденные и исправленные ошибки

1. **update_quantity** — при количестве 0 позиция оставалась в корзине с `quantity = 0`.
   Найдено тестом `test_update_quantity_zero_removes_item`, причина подтверждена в отладчике
   (docs/13_Debugging.md). Исправлено: при `quantity <= 0` позиция удаляется.
2. **cart_total** — ранее (практика №7, hotfix) суммировались только цены без количества.
   Тест `test_cart_total` закрепляет исправление и защищает от регрессии.
