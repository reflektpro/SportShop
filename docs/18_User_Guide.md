# 18. Руководство пользователя

**СпортТовары — система управления магазином**, версия 1.0.

Руководство описывает работу с программой из командной строки (терминал Windows, macOS или Linux,
в том числе встроенный терминал VS Code). Все примеры ниже выполнены на реальной программе,
вывод приведён без изменений (даты заказов соответствуют моменту запуска).

## 1. Перед началом работы

1. Установите Python 3.10 или новее и проверьте версию: `python --version`.
2. Получите программу: `git clone https://github.com/reflektpro/SportShop.git`, затем `cd SportShop`.
3. Все команды выполняются из папки `SportShop`.

Общий вид команды:

```text
python main.py [--data ПАПКА] КОМАНДА [параметры]
```

| Команда | Что делает |
|---|---|
| *(без команды)* или `demo` | демонстрация всех возможностей на встроенном сценарии |
| `catalog` | показать весь каталог |
| `search [строка] [--category К] [--min-price N] [--max-price N]` | поиск товара |
| `low-stock [--threshold N]` | товары с низким остатком |
| `stats` | статистика каталога |
| `cart show` / `cart add ID РАЗМЕР [КОЛ]` / `cart set ID РАЗМЕР КОЛ` / `cart remove ID РАЗМЕР` / `cart clear` | работа с корзиной |
| `checkout --client "ФИО"` | оформить заказ из корзины |
| `orders [--file ФАЙЛ] [--export ФАЙЛ]` | загрузить, показать и сохранить заказы |
| `analytics` | аналитика продаж |

Данные хранятся в папке `data/`: `products.json` — каталог, `cart.json` — корзина,
`orders.json` — заказы. Параметр `--data ПАПКА` позволяет работать с другой папкой данных —
так удобно тренироваться, не меняя основной склад. В примерах ниже используется копия каталога
в папке `demo_data`:

```text
mkdir demo_data
copy data\products.json demo_data\      (Windows)
cp data/products.json demo_data/          (Linux, macOS)
```

Справка по любой команде: `python main.py КОМАНДА --help`. Код завершения программы: `0` —
успешно, `1` — операция не выполнена (сообщение начинается с `[!]`).

## 2. Сценарий «Просмотр каталога»

Команда выводит все товары: идентификатор (ID — нужен для корзины), название, бренд, категорию,
цену, общий остаток и остатки по размерам. В последней строке — число товаров и средняя цена.

```text
$ python main.py --data demo_data catalog
 ID  Название             Бренд    Категория     Цена  Остаток  Размеры
  1  Кроссовки RunFast    Nike     Обувь         8990        4  40: 2, 41: 1, 42: 1, 43: 0
  2  Мяч Pro Match        Adidas   Мячи          2490       12  5: 12
  3  Гантели 5 кг         Torneo   Тренажёры     1590        1  5 кг: 1
  4  Футболка DryFit      Nike     Одежда        2990        3  M: 2, L: 1
  5  Ракетка Power        Wilson   Ракетки       5490        0  L2: 0
  6  Бутсы Predator       Adidas   Обувь        10990        8  40: 2, 41: 3, 42: 3
  7  Коврик YogaPro       Torneo   Йога          1990        3  183 см: 3
```

Ожидаемый результат: 8 товаров, средняя цена 4627,5 руб. Для краткой сводки по складу:

```text

```

## 3. Сценарий «Поиск товара»

Строка поиска ищется в названии, бренде и категории без учёта регистра. Фильтры можно
комбинировать: `--category` (точное совпадение категории), `--min-price`, `--max-price`.

```text
$ python main.py --data demo_data search nike
 ID  Название             Бренд    Категория     Цена  Остаток  Размеры
  1  Кроссовки RunFast    Nike     Обувь         8990        4  40: 2, 41: 1, 42: 1, 43: 0
  4  Футболка DryFit      Nike     Одежда        2990        3  M: 2, L: 1
Найдено: 2
$ python main.py --data demo_data search --category Обувь --max-price 10000
 ID  Название             Бренд    Категория     Цена  Остаток  Размеры
  1  Кроссовки RunFast    Nike     Обувь         8990        4  40: 2, 41: 1, 42: 1, 43: 0
Найдено: 1
$ python main.py --data demo_data search мяч
 ID  Название             Бренд    Категория     Цена  Остаток  Размеры
  2  Мяч Pro Match        Adidas   Мячи          2490       12  5: 12
Найдено: 1
$ python main.py --data demo_data search --min-price 5000 --max-price 100
[!] Ошибка: min_price не может быть больше max_price
```

Ожидаемый результат: по запросу `nike` — 2 товара; обувь до 10 000 руб. — только кроссовки
(бутсы стоят 10 990 руб.). Если минимальная цена больше максимальной, программа сообщает об
ошибке и ничего не ищет.

Товары, которые пора дозаказать (остаток ≤ 3, порог меняется параметром `--threshold`):

```text
$ python main.py --data demo_data low-stock
Товары с остатком ≤ 3:
  [5] Ракетка Power (Wilson) — 0 шт.
  [3] Гантели 5 кг (Torneo) — 1 шт.
  [4] Футболка DryFit (Nike) — 3 шт.
  [7] Коврик YogaPro (Torneo) — 3 шт.
```

## 4. Сценарий «Добавление в корзину»

`cart add ID РАЗМЕР [КОЛИЧЕСТВО]` — количество по умолчанию 1. Размер указывается так же, как в
каталоге: `40`, `M`, `"5 кг"`, `"183 см"` (размер с пробелом — в кавычках). Корзина сохраняется
в `cart.json`, поэтому её содержимое не теряется между запусками программы.

```text
$ python main.py --data demo_data cart add 1 40 2
[+] «Кроссовки RunFast» (размер 40) добавлен в корзину
Корзина:
  [1] Кроссовки RunFast (размер 40) × 2 = 17980 руб.
  Итого: 17980 руб.
$ python main.py --data demo_data cart add 8 M 3
[+] «Шорты Training» (размер M) добавлен в корзину
Корзина:
  [1] Кроссовки RunFast (размер 40) × 2 = 17980 руб.
  [8] Шорты Training (размер M) × 3 = 7470 руб.
  Итого: 25450 руб.
$ python main.py --data demo_data cart add 4 XL
[!] Размер XL отсутствует у товара «Футболка DryFit»
Корзина:
  [1] Кроссовки RunFast (размер 40) × 2 = 17980 руб.
  [8] Шорты Training (размер M) × 3 = 7470 руб.
  Итого: 25450 руб.
$ python main.py --data demo_data cart add 1 40 5
[!] Недостаточно товара размера 40: есть 2 шт.
Корзина:
  [1] Кроссовки RunFast (размер 40) × 2 = 17980 руб.
  [8] Шорты Training (размер M) × 3 = 7470 руб.
  Итого: 25450 руб.
$ python main.py --data demo_data cart set 8 M 1
[+] Количество изменено
Корзина:
  [1] Кроссовки RunFast (размер 40) × 2 = 17980 руб.
  [8] Шорты Training (размер M) × 1 = 2490 руб.
  Итого: 20470 руб.
$ python main.py --data demo_data cart show
Корзина:
  [1] Кроссовки RunFast (размер 40) × 2 = 17980 руб.
  [8] Шорты Training (размер M) × 1 = 2490 руб.
  Итого: 20470 руб.
```

Программа не даст положить в корзину несуществующий размер или больше товара, чем есть на
складе (с учётом того, что уже лежит в корзине). `cart set ... 0` и `cart remove ID РАЗМЕР`
удаляют позицию, `cart clear` очищает корзину.

## 5. Сценарий «Оформление заказа»

`checkout --client "ФИО"` оформляет заказ из корзины: проверяет остатки, списывает товар со
склада (`products.json`), добавляет заказ в `orders.json` и очищает корзину.

```text
$ python main.py --data demo_data checkout --client "Лаптев В.И."
Заказ №1 от 2026-10-09 09:38, клиент: Лаптев В.И.
  Кроссовки RunFast (размер 40) × 2 = 17980 руб.
  Шорты Training (размер M) × 1 = 2490 руб.
  Итого: 20470 руб.
Заказ сохранён в orders.json, остатки на складе обновлены.
$ python main.py --data demo_data checkout --client "Иванов И.И."
[!] Заказ не оформлен: Корзина пуста
$ python main.py --data demo_data cart add 2 5 3
[+] «Мяч Pro Match» (размер 5) добавлен в корзину
Корзина:
  [2] Мяч Pro Match (размер 5) × 3 = 7470 руб.
  Итого: 7470 руб.
$ python main.py --data demo_data checkout --client "Иванов И.И."
Заказ №2 от 2026-10-09 09:38, клиент: Иванов И.И.
  Мяч Pro Match (размер 5) × 3 = 7470 руб.
  Итого: 7470 руб.
Заказ сохранён в orders.json, остатки на складе обновлены.
$ python main.py --data demo_data search RunFast
 ID  Название             Бренд    Категория     Цена  Остаток  Размеры
  1  Кроссовки RunFast    Nike     Обувь         8990        2  40: 0, 41: 1, 42: 1, 43: 0
Найдено: 1
```

Ожидаемый результат: заказ №1 на 20 470 руб.; повторное оформление с пустой корзиной
отклоняется; остаток кроссовок размера 40 после заказа стал 0. Номера заказов продолжаются
между запусками программы (№1, №2, …).

## 6. Сценарий «Просмотр аналитики»

```text
$ python main.py --data demo_data analytics
Заказов: 2
Выручка: 27940 руб.
Средний чек: 13970.0 руб.
Хит продаж: Мяч Pro Match
```

Выручка — сумма всех заказов, средний чек — выручка / число заказов, хит продаж — товар с
наибольшим количеством проданных единиц (3 мяча против 2 пар кроссовок).

## 7. Сценарий «Сохранение и загрузка заказов»

выводит; `--export ФАЙЛ` дополнительно сохраняет загруженные заказы в другой файл (резервная
копия), `--file ФАЙЛ` загружает заказы из указанного файла.

```text
$ python main.py --data demo_data orders --export demo_data/orders_backup.json
```

## 9. Типичные сообщения об ошибках

| Сообщение | Причина | Что делать |
|---|---|---|
| `Товар id=N не найден` | неверный ID | посмотрите ID в `catalog` |
| `Размер X отсутствует у товара …` | такого размера нет | размеры указаны в последнем столбце каталога |
| `Недостаточно товара размера X: есть N шт.` | на складе меньше, чем запрошено | уменьшите количество |
| `Заказ не оформлен: Корзина пуста` | корзина пуста | добавьте товары командой `cart add` |
| `min_price не может быть больше max_price` | перепутаны границы цены | поменяйте значения местами |
| `Не найден файл каталога …` | неверная папка `--data` | проверьте путь, в папке должен быть `products.json` |
