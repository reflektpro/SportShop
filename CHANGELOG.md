# История версий (CHANGELOG)

Формат: [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), нумерация — семантическое версионирование.

## [1.0] — 2026-10-09 — первый официальный релиз (практическое занятие 10)

### Добавлено
- Консольный интерфейс `main.py`: команды `catalog`, `search`, `low-stock`, `stats`, `cart`, `checkout`, `orders`, `analytics`, `demo`; параметр `--data`; `--version`.
- Корзина сохраняется между запусками (`data/cart.json`): `load_cart`, `save_cart`.
- `next_order_id` и параметр `order_id` в `create_order` — сквозная нумерация заказов.
- 13 тестов `tests/test_cli.py` (всего 52 теста).
- Документация: README по шаблону, `docs/17_API_Reference.md` – `docs/21_Presentation.md`, диаграмма `docs/architecture.png`.

### Изменено
- `build.py` требует Python ≥ 3.10 (как указано в требованиях проекта).

### Исправлено
- `create_order` отклоняет заказ без имени клиента.
